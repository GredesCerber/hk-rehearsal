## 2. Требования

ID стабильные: на них ссылаются задачи в PRD (`req: [R1]`).

| ID | Требование (из ТЗ, своими словами) | Приоритет | В демо? | Источник в ТЗ |
|---|---|---|---|---|
| R1 | | must | да | «цитата до 15 слов» |
| R2 | | must | нет | |
| R3 | | should | | |
| R4 | | could | | |

Правило приоритетов:
- **в демо-пути** → `must`, задачи по нему — `risk:high`, делаются первыми;
- **must по ТЗ, но не в демо** → делаем упрощённо (минимально рабочая версия);
- **остальное** → `should`/`could`, по остаточному принципу; в питче — «в планах».
