**Что вывел kickoff.**
- Создал T6 (#7), T5 (#8) и эпик E1 (#9).

- T5 ссылается на `after` T2 и T3, которые закрыты.

**Почему так.** `kickoff` узнаёт задачи по маркеру `<!-- hk:task id=T1 hash=… -->` в теле issue. Маркеры остались в закрытых issues, поэтому задачи считаются уже созданными. Сообщение вводит в заблуждение: на деле issue закрыт и новых не создают.

**Что предлагаем.** Переименовать ID в PRD (например, T1 → T7 … T4 → T10), чтобы маркеры не совпадали, и повторить `kickoff --apply`. Пересоздать T5, T6 и E1 с новыми ссылками, либо отредактировать их вручную.
