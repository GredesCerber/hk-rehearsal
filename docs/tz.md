## ТЗ (как есть)

Задача
Веб-страница со списком покупок для одной семьи. Без регистрации.

Обязательно

1. Поле ввода и кнопка «Добавить» добавляют товар в список.
2. Пустой товар не добавляется: под полем появляется надпись «Введите название».
3. Клик по товару отмечает его купленным (зачёркнут). Повторный клик снимает отметку.
4. У каждого товара есть кнопка «Удалить».
5. Сверху видно, сколько товаров осталось купить.
6. Список хранится на сервере: `GET /api/items`, `POST /api/items`, `PATCH /api/items/:id`, `DELETE /api/items/:id`. Данные лежат в памяти сервера, после перезагрузки страницы список на месте.

Не делаем

* Вход и регистрацию.
* Несколько списков.
* Базу данных: хватает памяти сервера.
* Деплой.
* Красивый дизайн: достаточно аккуратного.

Демо (1 минута)

1. Добавить «Молоко» и «Хлеб».
2. Попробовать добавить пустой товар и увидеть надпись.
3. Отметить «Молоко» купленным: счётчик стал 1.
4. Перезагрузить страницу: всё на месте.
5. Удалить «Хлеб».

Оценка

* Демо работает.
* Есть тесты на каждый эндпоинт API.

Ограничения

* Стек: React (web) + Node.js (api).
* Время — 1 час.
