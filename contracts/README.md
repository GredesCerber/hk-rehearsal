# contracts/

Источник правды для API между зонами (web ↔ api ↔ внешние сервисы).

- `api.yaml` — OpenAPI 3.1. Его пишет architect в первый час, **до** параллельной работы.
- Из контракта генерируются типы и клиенты (например, `openapi-typescript` для web, pydantic-модели для api).
- Пока бэк не готов, фронт работает против моков из контракта (например, Prism: `npx @stoplight/prism-cli mock contracts/api.yaml`).
- Менять контракт можно только отдельной задачей с меткой `area:contracts` и ревью человека.
